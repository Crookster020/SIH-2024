# Project Bhujal 
## Smart India Hackathon 2024

Project Bhujal is a Godot-based educational game created for Smart India Hackathon (SIH) 2024. The game puts players in the role of a farmer managing groundwater resources, teaching sustainability through fun, decision-driven gameplay. Designed especially for school children, the game encourages responsible usage of natural resources and rewards the most efficient players via a global online leaderboard.

### What’s the Game About?
👨‍🌾 Play as a farmer making daily decisions: what to plant, how much water to use, and when to harvest.

💧 Learn how groundwater depletes or replenishes based on actions and weather.

⚖️ Balance crop yield with sustainable water use.

🧠 Educate players about real-world water challenges and resource management.

🏆 Compete with others on a live online leaderboard to see who manages resources best.

### Why This Matters
Groundwater is a critical resource for agriculture, especially in India. Project Bhujal aims to:

Raise awareness among children and young students.

Promote sustainable agricultural practices.

Encourage learning through play.

Support community-level competition and collaboration.

### Features
✅ Fully developed using Godot Engine

💡 Simple, intuitive controls designed for kids

☁️ Simulated rainfall, soil health, and well usage

📈 Performance-based scoring system

🌍 Online leaderboard to encourage healthy competition among students

🧒 Focused on ages 10–16, but enjoyable for all

### How to Run
1. Clone the repository:

```
git clone https://github.com/Crookster020/SIH-2024
cd project-bhujal
```
2. Open the project in Godot Engine:

	a. Launch Godot.

	b. Click on Import, and select the project.godot file.

	c. Run the game using the play button.

3. Optionally export to:

	Web (HTML5)

	Windows/Linux/Mac

	Android (for mobile play)
